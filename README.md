## 📝 نبذة عن المشروع
نظام **OMNI ERP** هو حل محاسبي وإداري متكامل مصمم لإدارة المنشآت والشركات بدقة عالية. يتميز النظام بواجهة مستخدم حديثة وتدعم تعدد العملات، التقارير الختامية، وإدارة المخزون والمبيعات.

### ✨ المميزات الرئيسية:
- **إدارة المنشأة:** إعدادات كاملة للبيانات، السجل التجاري، والنسخ الاحتياطي (JSON).
- **إدارة العملات:** تحكم لحظي بأسعار الصرف وحساب فروق العملة تلقائياً.
- **التقارير المالية:** استخراج ميزان المراجعة، قائمة الأرباح والخسائر، والميزانية العمومية.
- **نظام محلي آمن 100%:** حفظ البيانات محلياً باستخدام IndexedDB لضمان الخصوصية والسرعة.
